## 6. 마무리 정리

### 오늘 배운 것

| 개념 | 한 줄 정리 |
|---|---|
| 저장소 생성 (init/clone) | init은 새 프로젝트를 git으로 관리하기 시작하는 것, clone은 이미 있는 원격 저장소를 통째로 복사해오는 것 |
| Commit | 지금까지의 변경사항을 메시지와 함께 하나의 스냅샷으로 기록해서, 나중에 그 시점으로 되돌아올 수 있게 하는 것 |
| Push / Pull | Push는 내 로컬 커밋을 원격 저장소에 올리는 것, Pull은 원격 저장소의 최신 커밋을 내 로컬로 받아오는 것 |
| Branch | 원본(main)에 영향 주지 않고 독립적으로 작업할 수 있는 갈래 가지를 만드는 것 |
| Merge | 서로 다른 브랜치에서 작업한 내용을 하나의 브랜치로 합치는 것 |
| 충돌 해결 | 같은 파일의 같은 부분을 서로 다르게 고쳤을 때, 어떤 내용을 남길지 직접 선택해서 정리하는 과정 |
| Stash | 아직 커밋할 준비가 안 된 작업을 잠깐 서랍에 넣어두듯 치워두고, 나중에 다시 꺼내 이어서 하는 기능 |
